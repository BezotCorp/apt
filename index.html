Official package infrastructure

BezotCorp APT Repository

This endpoint hosts official BezotCorp Debian packages and the metadata required by APT. It is intended for Debian, Ubuntu, Kubuntu, and compatible Debian-based systems.

Repository design

  • Stable channel: stable
  • Component: main
  • Prepared architectures: amd64 and arm64
  • Repository metadata is generated and cryptographically signed by BezotCorp.

Packages

Packages are published here by their respective BezotCorp projects. The repository itself remains product-agnostic and rebuilds its global APT indexes whenever a Debian package is published.
